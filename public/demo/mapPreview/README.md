# 地图预览功能使用说明

## 功能概述
这个地图预览组件允许用户通过上传GeoJSON文件来动态渲染自定义地图，支持拖拽上传和点击上传两种方式。

## 主要特性
- 🗺️ 支持上传自定义GeoJSON地图文件
- 📊 自动生成随机数据用于可视化展示
- 🔄 可以重置为默认的中国地图
- 📱 响应式设计，支持拖拽上传
- ⚡ 实时预览，无需刷新页面

## 使用方法

### 1. 上传地图文件
- 将GeoJSON文件拖拽到上传区域
- 或点击上传区域选择文件
- 支持的文件格式：`.json`
- 文件大小限制：10MB

### 2. 文件格式要求
上传的JSON文件必须符合GeoJSON标准，包含以下结构：
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "name": "区域名称"
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [[[经度, 纬度], ...]]
      }
    }
  ]
}
```

### 3. 示例文件
在 `public/sample-map.json` 中提供了一个示例文件，可以用于测试功能。

### 4. 重置功能
点击"重置为默认地图"按钮可以恢复到默认的中国地图。

## 技术实现

### 核心功能
- 使用 `echarts` 的 `registerMap` 方法动态注册地图
- 通过 `FileReader` API 读取上传的JSON文件
- 自动验证GeoJSON文件格式的有效性
- 动态生成随机数据用于地图可视化

### 组件结构
- `LayoutTool`: 布局容器组件
- `el-upload`: Element Plus 上传组件
- `v-chart`: Vue ECharts 图表组件

### 数据流
1. 用户上传GeoJSON文件
2. 验证文件格式和结构
3. 注册新地图到ECharts
4. 生成随机数据
5. 更新地图配置和渲染

## 注意事项
- 确保上传的JSON文件包含有效的GeoJSON结构
- 地图的 `properties.name` 字段用于显示区域名称
- 上传成功后会自动生成随机数值用于颜色映射
- 支持地图的缩放和平移操作

## 扩展功能
可以进一步扩展的功能：
- 支持更多地图格式（如Shapefile、KML等）
- 添加数据编辑功能
- 支持自定义颜色主题
- 添加地图标注和标签
- 支持多图层叠加
